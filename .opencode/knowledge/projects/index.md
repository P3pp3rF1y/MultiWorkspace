# Project Definitions

Use this folder to capture mod project ideas from brainstorm through design.

## Active projects

- [Sophisticated Portals](./sophisticated-portals/index.md)

## Authoring rules

- Each project lives under `projects/<project-name>/` with an `index.md`.
- During early ideation, keep project content merged in project `index.md`.
- Split into feature files only when sections become large or decision-heavy.
- When splitting, keep a short summary and link in project `index.md`.
- Feature files stay design-focused (problem, value, MVP, risks, open questions).
- Keep implementation details out unless a task explicitly asks for them.

## Split recommendation triggers

- Section exceeds about 100 lines.
- Section has more than 5 unresolved decisions.
- Section has been revised across 3 or more sessions.
- Section needs independent tracking (for example balance tables or decision log).

When a trigger is met, notify the user with section name, reason, and proposed filename.
