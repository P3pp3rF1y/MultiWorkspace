# OpenCode Commands Index

Use this file as the lookup index for available OpenCode commands.

- `block-texture` -> `block-texture.md` - Iterate on a Minecraft block texture.
- `brainstorm-mod-feature` -> `brainstorm-mod-feature.md` - Brainstorm and prioritize Minecraft mod feature ideas.
- `build-review-loop` -> `build-review-loop.md` - Iterate implementation with a strict review gate.
- `cherry-pick` -> `cherry-pick.md` - Apply or adapt a commit from another Minecraft version branch.
- `smart-commit` -> `smart-commit.md` - Run the repository's commit workflow using the project's commit conventions. Aliases: `smart commit`, `smart_commit`, `smartCommit`.
- `design-build-mod-change` -> `design-build-mod-change.md` - Run a quick design then implementation review loop.
- `design-mod-solution` -> `design-mod-solution.md` - Converge on a mod solution design.
- `draft-texture` -> `draft-texture.md` - Draft a first-pass Minecraft texture prompt.
- `eod-report` -> `eod-report.md` - Generate a concise end-of-day agentic AI work report.
- `export-recent-sessions` -> `export-recent-sessions.md` - Export the most recent OpenCode sessions as JSON files.
- `merge-translation-pr` -> `merge-translation-pr.md` - Handle translation PR merge workflow.
- `port` -> `port.md` - Apply changes from this workspace to the other supported Minecraft workspaces.
- `port-all-to-brand-new-version` -> `port-all-to-brand-new-version.md` - Plan and port a MultiWorkspace set to a brand new Minecraft or NeoForge version.
- `resolve-curseforge-dependency` -> `resolve-curseforge-dependency.md` - Resolve a CurseForge project and file id conservatively.
- `review-session-improvements` -> `review-session-improvements.md` - Review one or more sessions for command, knowledge, workflow, and agent improvements.
- `review-mod-change` -> `review-mod-change.md` - Review a mod change with strict blocker and major gates.
